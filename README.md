# Low-Level Design Fundamentals 🏗️

A comprehensive guide to writing clean, scalable, and maintainable code. From programming paradigms to design patterns, this repo covers the essential building blocks every software engineer should know.

## What's Inside

### 01. Programming Paradigms

Learn the fundamental approaches to writing code:

- **Procedural**: Step-by-step instructions
- **OOP**: Object-Oriented Programming
- **Functional**: Pure functions and immutability

### 02. SOLID Principles

Master the five principles of clean object-oriented design:

- **S**ingle Responsibility
- **O**pen/Closed
- **L**iskov Substitution
- **I**nterface Segregation
- **D**ependency Inversion

### 03. Design Principles

Core concepts that make your code better:

- **DRY** (Don't Repeat Yourself)
- **KISS** (Keep It Simple, Stupid)
- **YAGNI** (You Aren't Gonna Need It)

### 04. Design Patterns

Proven solutions to common software problems:

- **Creational**: Factory, Singleton, Builder
- **Structural**: Adapter, Decorator, Facade
- **Behavioral**: Observer, Strategy, Command
- **Architectural**: MVC, Microservices, Event-Driven

## Getting Started

Each folder contains practical examples and explanations. Start from `01-programming-paradigms` and work your way through.

```bash
# Clone the repo
git clone https://github.com/yourusername/low-level-design-fundamentals.git

# Navigate to any topic
cd 01-programming-paradigms
```

## Who Is This For?

- Junior developers learning system design
- Engineers preparing for technical interviews
- Anyone who wants to write better code

## Philosophy

**Good code is not about being clever—it's about being clear.**

This repo focuses on practical, real-world applications of design principles. No unnecessary complexity, just clean fundamentals.

## Learning Path

1. Start with programming paradigms
2. Understand SOLID principles
3. Apply design principles (DRY, KISS, YAGNI)
4. Learn design patterns
5. Practice, practice, practice
